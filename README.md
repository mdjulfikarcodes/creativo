## 📖 About The Project

**Creativo** is a peer-to-peer marketplace where creators (filmmakers, photographers, podcasters) can discover and book unique studio spaces by the hour. Studio owners can list their spaces (cyc walls, podcast rooms, music suites) and manage bookings seamlessly.

### ✨ Key Features
- 🔐 **Secure Authentication:** Dual-layer security using Better Auth and JWT HTTPOnly Cookies.
- 🔍 **Advanced Search:** Filter studios by category, location, price range, and capacity.
- 📅 **Smart Booking System:** Real-time conflict detection (Double-Booking Prevention) ensures no overlapping time slots.
- 📊 **Dynamic Dashboard:** Interactive charts (Recharts) for revenue and booking trends, featuring smooth Framer Motion animations.
- ⭐ **Verified Reviews:** Users can only leave reviews after completing a booking.
- ❤️ **Wishlist:** Save favorite studios for later.
- 🖼️ **Image Upload:** Seamless image hosting via ImgBB.
- 📄 **PDF Invoice:** Downloadable receipts for confirmed bookings.
- 🌗 **Dark/Light Mode:** Smooth theme transitions.
